Reverse engineering

Passwords fall out of registers

Small C programs, stripped of symbols. Read the assembly, stop at the compare, and take the secret out of memory.

Setup

Nothing to install twice

One script fetches Juice Shop. One script builds the crackmes. The debugger ships with Xcode.

Safety

Pinned to loopback

Juice Shop normally listens on your whole network. grouse holds it to 127.0.0.1 or refuses to start.

Progress

Plain text

Each track keeps a checklist and a spoiler file. Tick things off as you go. Peek only when you are stuck.

How it works

Four steps, one machine

Every solve follows the same path, and the walkthrough shows each one in full.

StartOne script runs the shop on loopback. One builds the crackmes.
FindDevtools, gobuster and otool show you where the weak spot is.
ExploitOne request, one breakpoint, one quote mark in the right place.
ScoreThe benchmark checks the target's own scoreboard. Nothing is faked.

Start

Five commands in

Clone it, start the shop, then open the score board at localhost:3000/#/score-board. Free and open source; needs a Mac with the Xcode command line tools and Node.

git clone https://github.com/nulljosh/grouse
cd grouse
./pentest/run-juiceshop.sh    # the web track
./re/build.sh                 # the crackmes
python3 -I bench/bench.py     # score your solves

One rule

Only attack what you own or have written permission to test. Everything here stays on your machine. Pointing these skills at someone else's system without permission is a crime, and it is not what this is for. Read the rules.

FAQ

What is grouse?

A free pentesting dojo for your Mac. You attack a deliberately broken web shop and crack small binaries.

Do I need a VM or Docker?

No. Everything runs on localhost, so there is nothing to set up beyond the app.

Is it safe to attack?

Yes. The targets are broken on purpose and live only on your own machine.
